## 2024-05-24 - Interactive Elements Focus Visible Styles
**Learning:** Found several input elements (`input`, `textarea`, `select`) and custom interactive elements (`.sidebar-item`) without proper `:focus-visible` states, which makes keyboard navigation difficult. The project has a specific pattern for handling this: hiding default focus on mouse interaction via `:focus:not(:focus-visible)` and showing a 2px solid accent outline on keyboard focus via `:focus-visible`.
**Action:** Always verify all interactive elements (buttons, links, form inputs, and custom interactive div/span elements) have clear `:focus-visible` styles matching the design system pattern, while suppressing the default outline for mouse users using the `:focus:not(:focus-visible)` trick to prevent cascade bugs.
