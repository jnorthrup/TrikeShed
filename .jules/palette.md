## 2024-05-19 - Semantic Buttons for Interactive Divs
**Learning:** In the Forge workspace sidebar, interactive elements like `.workspace-switcher` and `.drop-zone` were implemented using `div` tags with `role="button"` and `tabindex="0"`. While this makes them focusable and readable by screen readers as buttons, it lacks native button behaviors (like activating on Space/Enter without custom JS) and can lead to inconsistent accessibility experiences compared to semantic HTML.
**Action:** Replace `div` elements acting as buttons with native `<button>` tags when possible. Remember to reset native button styles (like `border: none; background: transparent; width: 100%; font: inherit; color: inherit;`) in CSS to preserve the original design while gaining semantic and functional benefits.
