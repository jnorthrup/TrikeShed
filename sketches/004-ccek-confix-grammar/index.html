CCEK ⇄ CONFIX Coroutine.Context.Element.Key (live, wide E·K sets) ⇄ ConfixIndexK (static, GADT facets) — the same faceted row, two grammars
thesis: a CCEK stack IS a FacetedRow — Key = OpK<R> (the GADT key fixing the result type), Element = the facet value. The coroutine resolves get(Key): Element exactly as ConfixIndex resolves facet(OpK): R — one unchecked cast at the dispatch boundary. Wide sets: N keys ride one context; they rarely modulate each other (a gate reads another element) and rarely externalize gates — but both happen, so the row carries them as ordinary facets.
