TRIKESHED ARCHITECTURAL I/O MAP
===============================

Scope: package-grouped map of the production-facing units and their principal
I/O. This is not a module list: arrows name the artifacts crossing boundaries.
Canonical identity is ContentId = sha256:hex across all six lillypad rings.

  ───> durable / primary data flow       - - -> asynchronous observation
  <───> bidirectional protocol flow      [pkg] package group / implementation
  {…}  artifact shape                    (!) current lifecycle pressure point

                           FORGE-OBSERVABLE PRODUCT LOOP

  source / repo / document
      ───> Ring 0 blob CID
      ───> Ring 1 LineSpine + structural evidence
      ───> Ring 2 logical provenance / memory index
      ───> Ring 3 causal work / patch / branch state
      ───> Ring 4 board / graph / gallery projection
      ───> user inspects evidence and starts next action

  Required canonical closure:

  worker branch or raw patch
      ───> CAS patch CID
      ───> branch/patch ingress record
      ───> confluence/materialization
      ───> canonical master
      ───> MergeReceipt or SupersessionReceipt
      ───> Forge-visible CLOSED work state

  A branch that is not contained by master and has no terminal receipt is a
  live unresolved causal unit. It must be visible and actionable in Forge.


PACKAGE GROUPING NOTES
  lib / collections / cursor / common
    Kernel algebra: Join, Series, Cursor, lazy projections, indexed shapes.

  cas / job / userspace.nio.file.spi / couch
    Durable bytes, content identity, WAL, logical attachments and projections.

  context.nuid / dht / litebike / userspace.nio / htx
    CCEK element context, routing, bind/accept, and userspace network I/O.

  dag / graph / causal / pointcut / mutable
    Rete evaluation, causal graph projection, interception, mutation routing.

  jules / daemon / pijul / modelmux
    Remote executor adaptation, orchestration, patch materialization, model/key
    routing. These must converge through receipts, not independent counters.

  forge / kanban / forge.blackboard / forge.gallery
    Product boundary: source ingest, canonical board, causal graph, RTS/gallery,
    inspection surface.
