Package: @earendil-works/pi-agent-core 1.5.0
The agent, agent-loop and schema code are real upstream source, not a substitute loop.
The local fixture-entry.ts supplies an in-memory response and recall tool. It does
not call a model, retain host breadcrumbs, run the Pi coding-agent CLI, or grant tools.

Upstream MIT notice is in LICENSE-pi.txt. Bundled schema format checks adapted
from TypeBox carry the additional MIT notice in LICENSE-typebox.txt.

manifest.json records source hashes and the exact fixture and bundle hashes.
Rebuild with the pinned checkout, Node 24.19.0 and webpack 5.108.1: use a loader
that returns node:module.stripTypeScriptTypes(source, {mode:'strip'}) for .ts;
set target=web, mode=none, optimization.minimize=false, resolve.extensions=[.ts,.js].
Alias @earendil-works/pi-ai exactly to a barrel re-exporting only these upstream files:
packages/ai/src/utils/transcript.ts
packages/ai/src/utils/event-stream.ts
packages/ai/src/utils/identity.ts
packages/ai/src/utils/validation.ts
Alias @earendil-works/pi-schema to packages/schema/src/index.ts, and its /formats
subpath to packages/schema/src/formats/index.ts. Use fixture-entry.ts as entry.
The recorded generation used /workspace/library-files/pi-agent-proof/bundle.cjs;
paths affect webpack comments, so compare input hashes as well as bundle hashes.
No third-party code was fetched or installed during bundling.

Runtime proof uses fixture-only AbortController, JSON-only structuredClone and a
Date.now performance clock. They are deliberately incomplete browser API substitutes;
production cancellation, clone fidelity, monotonic timing and host transport remain
unimplemented. Tests cover a genuine upstream turn and schema-validated fixture tool
loop in restricted Graal JS, including a child JVM. They do not certify containment.
