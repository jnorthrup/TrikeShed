# utils/ipfsindex: content-addressed indexes over pinned corpora

Offline-first indexing utilities. Everything here is keyed by content hash (sha256 now, CIDv1 where
noted) and carries provenance back to a pinned upstream object. Nothing here asserts legal conclusions.

    legal/    indexes over statutes, constitutions and Federal Register receipts

Upstream design references (read-only leads, not vendored): endomorphosis/ipfs_datasets_py and
ipfs_accelerate_py, both AGPL-3.0, same as TrikeShed. See NOTICE.md.
