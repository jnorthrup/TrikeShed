# Shake Demo

One offered palette/gallery item: `preset-shake` (catalog title: Shake Demo).
It opens in the existing harness and is generated from `LcncContracts.all()`.
It does not create another UI or maintain a second vocabulary.

Every advertised node type appears once as a subject. Each input has a typed
`scope.in` counterpart and each output a typed `scope.out` counterpart.
These are frame bindings and yields, not fabricated working credentials,
process handles or network responses. Types without sockets are included too.
The initial document contains zero wires. The complete counterpart assignment
exists only as a test oracle and is never installed by opening the item.

An eight-level scope specimen sits beside the palette. It includes named
inputs, argument envelopes, guards, composed returns and named yields. The
same builder is tested at depths 1, 8 and 16, including repeated invocations
with different caller bindings. Depth is bounded at 16.
Additional cases cover an argument-map override at depth eight, explicit named
input precedence, and Shake limited to a deep selected parent without changing
outer nodes or an existing outer wire.

## Shake Coverage

Tests enumerate the real socket declarations, including optional and dynamically
declared scope ports. They require every socket to have a counterpart and check
the full hypothetical assignment with the existing type and scope checker.
Moving the nodes must not alter that compatibility result.

Ordinary Shake on this inspection-only specimen includes optional and effect
sockets. It uses augmenting-path matching with consistent per-node generic type
bindings, then validates the resulting graph with the shared type and scope
checker. Distance ranks alternatives but does not exclude compatible counterparts.
The test oracle is not available to the matcher. Starting positions can change
which compatible sockets pair, but the tested layouts all reach full coverage.

Executable programs retain their existing reach, optional-port, argument-map
precedence and effect protections. Complete wiring of the palette specimen does
not make its placeholder bindings a meaningful or authorized executable program.
Missing counterparts remain open; the status reports connected sockets from actual
wires and never rounds a partial result up to 100 percent.

Specimen matching is bounded to 1,500 nodes, 32 scope levels, 2,048 open sockets,
64 type-binding combinations and 4,000,000 candidate-filter/alternating-path
steps. These are separate bounds, not an elapsed-time guarantee. Selection limits
new proposals while preserving existing wires and enclosing context.

## Execution Guard

The item has `controls.inspectionOnly` set. The harness disables Run, and the
procedure runner refuses it before dispatch, including named subprogram entry.
The flag survives Confix round trips and ordinary draft publishing. It is a
document-level accident guard, not a security sandbox or capability policy;
an explicitly reauthored document is a different program.
