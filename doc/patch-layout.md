# Local Patch Gravity

FD settles the selected parent's direct children around existing cables and
nearest legal candidate patches. The Shake Demo (`preset-shake`, generated by
`LcncShakeDemo`) is the comprehensive socket specimen and is offered in the
palette. The layout has no specimen-name or counterpart-name rules.

## Authority and Geometry

- Candidate pulls come from the existing server `LcncTreeShake` matcher. Layout
  requests a wide search reach so distant compatible parts can be brought
  together. Matching still enforces types, scope, optional-input and effect
  rules. Ordinary Shake retains its own reach; FD never installs a cable.
- Existing wires and candidate links pull measured port positions together.
  Output-to-input direction is a soft preference, so feedback cycles do not
  create indefinitely increasing columns. This is not a global shortest-path
  or crossing-minimization guarantee.
- D3 force integration settles each connected segment independently. Rectangle
  separation reserves 32 parent-local units between boxes, followed by a
  nearest-free-space pass. Disconnected segments pack with 72-unit gutters;
  they acquire no synthetic semantic or execution relationships.
- Scope children stay in their parent's coordinate system. Descendant cables
  project onto the enclosing box, without laying out the descendant interior.
  A grown top-level assembly moves to vacant space if necessary; neighboring
  programs and their documents are not moved.
- A successful settlement is one document save/undo step. Changed selection,
  document, node identity or measured frame invalidates the pending result.
  Matching failures leave only existing-cable attraction and report that
  limitation. Solver failures leave geometry unchanged.

## Bounds

The matching request is limited to 1,500 document nodes, 32 nested levels,
1 MiB request and 2 MiB streamed response. Its fetch abort deadline is eight
seconds; aborting the browser request is not proof of server cancellation.

The solver accepts at most 1,500 boxes and 4,096 patch links. It runs 160 stopped,
manually driven D3 ticks per connected segment, with at most eight million
custom collision/patch visits and 4,096 vacancy candidates per box. A checked
two-second wall-clock budget and periodic browser yields bound settlement;
these are cooperative limits, not real-time preemption of JavaScript or D3.
No simulation timer continues after completion or failure.

## Shared Node and Browser Code

`src/commonMain/resources/web/patch-layout.js` exports the same solver to Node
tests and the browser. It uses the vendored, offline bundle
`vendor/d3-force-3.0.0.js`: d3-force 3.0.0, d3-quadtree 3.0.1,
d3-dispatch 3.0.1 and d3-timer 3.0.1. Their original ISC licenses are beside
the bundle. Only forceSimulation, forceLink, forceX, forceY and quadtree are
exported. Bundle input imports those symbols from their packages; esbuild
0.25.9 emits a minified IIFE named PatchForces plus its CommonJS export.

The [D3 simulation documentation](https://d3js.org/d3-force/simulation)
describes stopped simulations and manual ticks. Rectangle clearance and port
offsets are the patch-editor-specific constraints, not a second integrator.

## Verification

```text
./gradlew jvmMainClasses --console=plain
node --test src/jvmTest/js/patch-layout.test.cjs src/jvmTest/js/landscape.test.cjs src/jvmTest/js/shake-demo.test.cjs
PATCH_BASE_URL=http://127.0.0.1:8898 node src/jvmTest/js/patch-layout-browser.check.cjs
```

The browser check optionally accepts `SHAKE_ENTRY`, a retained blackboard entry
JSON file. It mounts the specimen only in its isolated test page; it does not
publish it. Desktop and mobile checks assert unchanged cables and neighboring
program coordinates, direct-child clearance, no top-level territory overlap,
nonblank canvas, nested-scope layout, and actual Shake cable rendering.

The 2026-09-05 preview measured 528 top-level boxes, 135 independent segments
and 393 candidate pulls in a retained Shake specimen. Summed straight-line
candidate-patch length fell from approximately 262,018 to 74,979 parent-local
units (71% shorter). This measures the same proposed endpoint pairs before and
after placement, not executed work or a claim of globally optimal wiring.
