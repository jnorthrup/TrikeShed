## Risk register

| Risk | Early signal | Mitigation | Stop condition |
|---|---|---|---|
| Visual activity outruns retained truth | Sparks lack receipts or terminal events | Event identity and projection invariants | Do not advertise live proof |
| Branch explosion | Frontier grows faster than completions | Global budget, memoization and breadth preview | Refuse additional admissions at cap |
| Source semantics lost | Negation/exception disappears | Exact spans and unresolved structures | Withhold affected formalization |
| Scope leakage | Hypothetical facts appear globally | Explicit datasets and frame checks | Suspend affected production generation |
| Confidence inflation | Replays increase evidence | Stable receipts and exact dependence | Reject/recompute contaminated experiment |
| Native worker hangs | Deadline passes without cleanup | Process supervision and descendant reaping | Mark attempt incomplete; no result |
| Production stale at dispatch | Review changes after match | Generation/currentness fence | Refuse effect and return to analysis |
| Memory/storage growth | Unbounded queues or journal rate | Batches, retention roots and admission caps | Stop new work before required evidence is lost |
| Optional model dominates CPU | Long latency without quality gain | Deterministic baseline and measured selection | Keep model optional/unavailable |
| Integration erases intent | Blanket side selection or hidden exclusions | D3M archive, intent review and composed checks | Do not advance master |
| Cost escalation | Cache misses/repeated failed attempts | Per-task budgets and 48-hour recalibration | Pause spending on blocked work |

## Experiment E01 Human aggregation

Question: what projection interval and visual encoding let a person explain a branch without slowing the engine? Compare 100, 250 and 500 ms aggregation at fixed event rates, with particles versus bands. Measure frame time, lag and time to identify the blocking dependency. Keep underlying events identical. Choose the simplest encoding meeting the task and performance target; a more animated screen is not automatically better.

## Experiment E02 Structured premise selection

Question: can class/argument indexes reduce solver work while preserving the declared fixture answer? Use F04 with 1,000 distractors, exact role swaps and missing support. Compare full theory, flat top-16 and structured bounded selection before solving. Report coverage and proof correctness separately. Stop generalizing if selection completeness cannot be characterized beyond the fixture.

## Experiment E03 Parser profiles

Question: which local profile adds useful structure at acceptable cost? Compare syntax-only and any richer profiles on frozen passages with exact anchors and condition annotations. Include copied-node and historical-record handling from the current upstream follow-up. Measure semantic candidate errors and refusals, not merely token count. Preserve unresolved scope; no profile wins by dropping hard examples from the denominator.

## Experiment E04 Optional model contribution

Question: do BERT reranking or Jeva selection improve required-premise recall or routing quality over lexical/structural methods? Pin model/runtime and test actual local inference. Include abstention, option permutation, long passages and out-of-domain cases. Retain cost and memory. If improvement is negligible or resource use exceeds the target profile, leave the lane optional.

## Experiment E05 Empirical production

Question: can a learned routing hypothesis save work on held-out episodes without unsafe actions? Use source-family-separated splits and explicit counterexamples. Compare deterministic policy, NAL hypothesis and any optional model policy. Start with local routing/cache effects. Stop before deployment if evidence dependence, calibration or fallback cannot be explained.

## Experiment E06 Incremental maintenance

Question: when does incremental invalidation outperform bounded full recomputation? Generate positive theories with controlled alternative support and source deletions. Compare exact results and dependency coverage after every update. First-proof-only output cannot support an assumed complete justification graph. Add richer provenance or use conservative recomputation where required.

## Experiment E07 Broader logic

Question: which unsupported construct blocks a real domain question? Select one: explicit negation, temporal constraint, quantifier or defeasible exception. Define its semantics and a small independent reference corpus before choosing a backend. Do not flatten it into the existing Horn subset. A successful experiment adds one declared fragment and its failure modes, not a claim of full legal reasoning.

## Experiment E08 Airgap portability

Question: does a clean target machine run the selected workflow without hidden cache/network dependencies? Install the sealed bundle on the named hardware, deny egress, remove optional assets in controlled variants and run the storyboard. Track browser and descendant processes. A process-only network filter result is recorded at that scope; it does not become a physical-airgap certificate.

## Remaining owner decisions

Before D2, choose the exact agreement capture/jurisdiction, publishable PDF fixture, reference workstation, permitted local effect classes and review policy. Defaults in this package permit technical progress with synthetic assumptions. Before D3, choose retention periods, recovery objectives, bundle distribution and domain-review staffing. Before expanding production authority, define the actual target system and its idempotency/reconciliation contract.

These decisions are implementation inputs, not reasons to stop writing or building independent mechanics. Each unresolved decision has a bounded placeholder fixture and a clear gate before it affects real authority or publication.
