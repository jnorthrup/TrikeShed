A named graph selects the source assumptions for a query. Retain each curation tuple's graph, subject, predicate and object, and resolve its terms through explicit mappings and an inspectable lexical sidecar. Graph selection constructs an immutable theory; it does not silently add a context argument to every predicate. Identical labels in different documents remain different entities unless a reviewed identity mapping joins them.

Statement kind determines admission. Extraction observations describe what was retained or reviewed. Document statements and MUST/MAY/MUST_NOT/PRESUMED norms describe source content. Neither becomes a world fact merely through review. A separate, explicit source-assertion format would admit positive unconditional instance/subclass propositions as assumptions in a named source context, binding exact quotations, original/text CIDs, source revision, ontology/mapping IDs and host-issued review lineage. Caller-supplied approval flags cannot supply that authority.

The synthetic demonstration makes this boundary visible. Filing A's named context admits two quotation-backed assumptions that its “Exhibit A” is a Certificate. Filing B uses the same label but has another context and opaque entity ID; its candidate is excluded from A's frame. The frame also names the verified SUMO edges Certificate→Text and Text→ContentBearingObject and an explicitly sourced instance/subclass propagation rule. This admission is deliberate fixture construction, not a newly implemented production assertion receipt. The current authenticated production path reasons about review-record metadata only.

Actual SumoNixBridge compilation produces registered SUMO/KIF MLIR and a provenance sidecar. Native sumo-to-kif and kif-to-nix lowering produces ordered facts/rules; the pinned native Horn evaluator then returns a source-attributed result. Each of the demonstration's six complete native results matched official Nix. A's classification is SUPPORTED under its selected assumptions. Removing one quotation retains the other witness; removing the last produces UNKNOWN. B's classification inside A's frame and the absent local:ServedOn predicate both remain UNKNOWN. This establishes no service, legal validity or obligation applicability.

A derived receipt should identify its input frame, query, checked proof, exact source clauses and ontology/rule/policy versions. Keep any future persisted receipts in a separate versioned derived graph, with edges from conclusion to logical rule and source clauses. The current native certificate validator checks rule identities, substitutions, ordered premises and asserted witnesses relative to the trusted host-generated input; it does not authenticate arbitrary caller-authored provenance. Duplicate asserted sources are alternative witnesses, not joint premises or independent votes, and the backend returns only its first derived proof. Source changes require a new frame; older receipts remain historical.

The next semantic slice is explicit asserted-taxonomy admission, not full first-order logic. Conditions, temporal/jurisdictional scope and exceptions require their own reviewed semantics. Absence of an exception is not evidence that it does not apply. Quantified, functional, negative and higher-order formulas remain outside this positive scalar Horn backend and must stay retained with explicit exclusions or go to a separate proof backend. UNKNOWN never means refutation, and timeout or refusal never becomes UNKNOWN.
