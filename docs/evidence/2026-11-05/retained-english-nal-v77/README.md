# Retained English NAL: v77 direct CLI evidence

This records fourteen actual production CLI processes against frozen v76/v77 JARs. The new explicit historical mode reads genuine retained English inspection receipts through `EnglishObservationGraph.read`, then evaluates a bounded atomic-symbol profile using the existing one-level NAL deduction and weak induction rules. It does not execute a parser or admit beliefs. The default zero-argument experiment remains a separate fixed example and has byte-identical old/new stdout (25,531 bytes).

The final build passed all 480 tests, with no failures, errors or skips, and all three JS builds. This package contains recorded data and a Python auditor, not production JARs, dependencies, classes, models, or a replacement engine. The CLI port is observed directly; no browser/UI or HTTP socket claim is made.

## Replay without Java

Requires Python 3.9+ and a fresh nonexistent extraction directory. From this directory:

```sh
python3 replay-recorded.py --extract /tmp/retained-nal-v77-fresh-replay
```

The wrapper verifies `SHA256.json`, bounded regular archive members against `records-manifest.json`, and safe extraction before invoking the unchanged independent auditor in recorded-only mode. It requires byte equality with `recorded-audit-result.json`. It launches no JVM, parser, browser, build, or query engine and needs no live REF target. The exact lower-level auditor invocation and strict-local-artifact scope are in `recorded-audit-usage.txt`.

The recorded-data audit passed and rejected six copied-report mutations: changed term identity, reversed ordered deduction premises, erased source basis, changed weight, weak induction relabeled as deduction, and structural evidence presented as NAL confidence. The strict audit additionally checked the then-present frozen JAR/Java bytes. Both reports are included unchanged. `SHA256.json` hashes every outer package file except itself; `records-manifest.json` hashes all 177 archive members (7,172,828 uncompressed bytes). These hashes identify evidence bytes; they are not an independent origin signature or OS seal.
