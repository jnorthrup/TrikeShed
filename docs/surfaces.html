Operator surfaces

The pages the Oroboros daemon serves — the same files, published here.

These are shells. Every surface reads its data from the daemon's API, so opened as static files they render their layout and no content. To see them live: bin/oroboros-up --fresh --port 8899, then http://127.0.0.1:8899/.
  • harnessThe LCNC harness: the node palette, presets, and a program's run receipts.
  • panelsPatch panels: cables between typed ports, laid out on one canvas.
  • kanbanThe board. Cards claim themselves, a coding agent works them in a scratch clone, the plane judges the result.
  • documentsMounted project documents, rendered from commonMain.
  • graalThe Graal console: VM worlds, pointcut facts, the terrain view.
  • hermes-xtermHermes on a no-native GraalPy sleeve, on an xterm-256color panel with a real cursor.
  • vm-terminalOne terminal tab per supervised VM or process.
  • muxModelMux and KeyMux: which models are reachable, and on whose key.
  • futonThe Couch 1.6 surface over the daemon's own store.
