This is a maintenance/security update. It fixes resource loading through the
thread context classloader, relevant to guest modules, and adds enhanced-graph
Semgrex queries, query statistics and SUTime fixes. Optional Semgrex nodes now
enumerate every match; consumers must check result cardinality. Enhanced queries
require an enhanced input graph. No Semgrex or FULL/KBP parity is claimed by the
SYNTAX comparison below. The published POM identifies GPLv3; upstream README says
GPLv2or later. Preserve the existing license/resource notice handling.

Actual artifact compatibility
The bridge classes have classfile major55(Java11), matching the release minimum,
despite the POM's older compiler setting. Their six inspected public APIs match
4.5.10. The JAR has no module-info descriptor and names automatic module
edu.stanford.nlp.corenlp; the existing URLClassLoader remains the classpath boundary.
Six selected English model resources(POS, UD/SD dependency parsers and three NER
models) are byte-identical across4.5.10/4.6.0. Do not describe this as better English
weights or general language comprehension.

FULL compatibility follow-up
Before installation promotion, the same frozen host JAR also executed FULL in
two fresh JVMs on two short synthetic legal-language sentences per version.
Both passed exact source/token/copy-graph checks with the unchanged FULL
configuration(tokenize,ssplit,pos,lemma,depparse,ner,natlog,openie,kbp;
kbp.maxlen100). Sentence lengths were9and11tokens. Each version emitted seven
actual OpenIE triples; their token spans/glosses/confidences were retained and
structurally checked. The named example produced PERSON and ORGANIZATION tags.
KBP ran but emitted zero relations, so nonempty KBP slot output is not validated.
The positive-if candidate retained its condition; the negated-unless example
emitted no interpreted norm despite two raw OpenIE triples. All remain unreviewed.

Both FULL children exited0 without timeout under the same4GiBheap/180s/outbound
denial bounds. Observed wall times22.756s/17.561s and kernel peakRSS
3,159,492/2,897,564KiB are single observations, not comparative performance claims.
The two observed structural output pairs were identical; general FULL/KBP parity,
long-document performance and legal interpretation are not established. No private
PDF was parsed with FULL, and no NARS, ModelMux, review or corpus admission occurred.
See full-smoke.json and full-observed-synthetic.json in the evidence directory.

Offline provisioning
On a staging/build machine resolve the declared bundle explicitly:
  ./gradlew -p utils/subvm installCorenlp
For disconnected deployment transfer the complete corenlp/ directory with its
lib/ and MANIFEST.tsv under the selected subvm root. Keep an independently
verified prior bundle for comparison/rollback. Set TRIKESHED_SUBVM_HOME to that
root, or JVM property trikeshed.subvm.home, before starting a fresh daemon.
GuestModules verifies installed JARs before mounting. Runtime parsing uses those
local resources; the airgap model-egress switch is not general OS network isolation.

Verification preserved installed4.5.10unchanged; its original28manifest entries
still matched. A separate external4.6.0bundle supplied the comparison. Promotion
of the actual local installation is a separate deployment operation.
