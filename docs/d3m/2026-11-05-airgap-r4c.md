## Resulting behavior

The packaged recovery entry verifies retained document revisions before
registering native runners. A started direct run interrupted by process exit
is retired through the existing durable owner. The user can explicitly
submit a distinct new run against the same program and sources, then inspect
both records in a third JVM without extraction or native execution.

The incoming source-promotion and English guard records retain their own
artifact identities. The NAL implementation reads bounded historical English
frames, derives one level of atomic-symbol hypotheses and preserves full
source and evaluator preimages. It neither authenticates earlier parser
execution nor grants review/publication authority. The CLI checks complete
quiescent pack framing before opening the existing store, preventing its
normal tail-recovery behavior from silently repairing the inspected input.

The [R4c runbook](../airgap/08-interrupted-execution.md) records the runtime
scenarios, independent audit, build evidence and open gates. All frozen tips
must remain ancestors of publication, and any concurrent master advance
must be integrated before an ordinary push. Jim's local Mac checkout is
outside this execution environment.
