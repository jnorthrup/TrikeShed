## Verification and scope

The combined source compiled JVM main and all JVM test sources and passed
**219 selected JVM regressions with zero failures, errors or skips**. Selected
coverage includes native scalar/Confix ownership, document spans, copied
geometry, recorded consumption, source currentness, durable project binding,
KIF/RDF fidelity, required-anchor coverage, reviewed proof paths, curation
and model airgap policy. JS main, production Documents and Spacegraph bundles,
Wasm-JS, Wasm-WASI and Linux x64 also compile. Both build invocations used

The [R4a runbook](../airgap/06-offline-runtime.md) distinguishes that build
environment from the packaged runtime's stricter filesystem boundary. It
records the live document run, actual process restart, unchanged receipt and
source identities, launcher dependency findings, startup refusal controls,
package integrity checks and remaining source-build closure work.

The final evidence packet and publication record retain full commit IDs,
commands, hashes, build logs and source equivalence checks. The generated
runtime archive is a local release artifact; it is not added as a large
binary to Git. Source, packaging declarations, runbooks and immutable proof
records are committed. The full daemon, arbitrary OCR inputs, other CPU
architectures, power-loss recovery and vendor source-build reproducibility
are outside this bounded increment.
