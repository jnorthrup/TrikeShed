## Intent and repairs

- R2 executes the real upstream Confix scanner under an owned serial kernel
  seat, copies bounded results, releases native allocation and retains source
  plus whole-program LCNC receipts. The first test run exposed lazy Series
  views surviving native free. Explicit eager copies of rows **and children**
  fixed that boundary; serialization after Context closure now exercises it.
- The copular branches preserve syntax evidence without asserting truth. Their
  retained parser fixture and all 104 v68 manifest entries were checked.
- Panels fixes settle invalidated workspace loads and bind immutable receipt
  inspection to drawer/selection ownership, preserving captured-canvas identity.
- English taxonomy adds explicit authenticated declarations and review; the
  shared decoder intentionally tightens CBOR limits to 16 MiB, depth 64 and
  one million items. Export guards prevent unreviewed evidence promotion.
- D3M now explicitly enumerates/fetches all remote heads, because `fetch --all`
  alone still honors a narrow per-remote refspec.

Independent source review found no merge-blocking semantic collision. The
English taxonomy branch's final browser workflow still needs its own exact
artifact verification; historical v68/v69 browser evidence is not proof of
this combined artifact.
