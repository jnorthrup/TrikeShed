# R4d verification packet

verification.json records the combined JVM build and tests, fresh affected-target
compilation, seventeen browser cases, traced directory barriers,
selected WAL-fsync faults and archive identities. The independent WAL audit
checks actual CRC32C frames and CAS pointers. EIO and SIGKILL can leave a
completed frame readable after reopening even without a successful response;
no second run is submitted. The EIO writer retains its nonzero shutdown error.

preliminary/ retains the original missing-directory-barrier traces, corrected
trace, initial exit-status, response-capture, stale-inspection and shutdown-response harness errors, successful
preliminary proofs, and a two-file check of path-filtered injection. checks/
and harness/ retain the original incorrect first-status and numeric-index
audits as well as the accepted audit. Raw bytes are preserved.

The runtime and source archives are separate large deliverables. This is
process/syscall fault evidence with a surviving host kernel, not a power-loss
claim or complete vendor-source rebuild. D3M evidence is retained separately.
