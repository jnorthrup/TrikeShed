Reviewed KIF taxonomy source

The document review surface may offer positive ground `(subclass A B)` and
`(instance a B)` forms from a retained `.kif` document. The source must decode
as UTF-8 and its extracted text must have exactly the original bytes' content
identity. The scanner checks complete top-level syntax and source spans. Forms
inside comments, strings, quotation, negation, rules, or other nested forms
are not offered as positive assertions. The first 256 candidate rows are shown;
later candidates can be browsed in bounded pages by an authenticated reviewer.
The reviewer can collect IDs from multiple pages into one snapshot; changing
the reviewer credential clears that selection, and the host rechecks the source
and every ID when retaining it. A snapshot permits 256 selections, while a
native query permits at most 123.
Regular snapshots from the same source still supersede one another. A reviewer
may instead freeze a numbered partition: the number is the candidate ordinal
divided by 32, and every selected assertion in that partition snapshot must
belong to that one partition. Each partition has its own review family; a later
snapshot in that partition supersedes its previous approval. This versioned kind
does not reinterpret existing regular snapshots or their review history.

Authenticated `/taxonomy-union` accepts up to 16 distinct current approved
snapshots, including partitions from one or more sources. It checks the heads
together under the review actor, verifies each source and its exact quotations,
refuses overlapping source occurrences, and checks all heads and source revisions
again after native execution. The result retains each approval and occurrence
identity. With more than 123 reviewed assertions, the host scans the reviewed
facts for a candidate path and submits only that path to the native solver.
The solver checks the path and returns its first positive proof; the scan is
not itself a proof. If no candidate is found or the path exceeds 60 edges,
only the first 60 assertions are submitted. The result reports the number
reviewed, the number actually queried and the projection reason. UNKNOWN is
scoped to that native slice, not an exhaustive result over a large corpus.
This read grants no sink authorization.

Authenticated `/taxonomy-chain` offers an opt-in positive path over the same
approved selections. It searches for a path of up to 256 edges and verifies
segments of at most 16 original assertions separately using the pinned native
solver and its certificate checker. The host composes the verified segments
using subclass transitivity and, when applicable, instance inheritance; it does
not turn derived intermediates into approved source assertions. The response
contains the native proofs and source occurrences for each segment. All heads
and sources are checked again after execution, and the entire operation shares
one native profile wall limit. A missing or longer path is refused, not treated
as a refutation. The existing snapshot, source byte and selection limits still
apply; this is not exhaustive inference over an unbounded corpus.

The host re-resolves selected IDs from the retained record. An authenticated
analyst approves the exact snapshot using the existing review ledger. A later
read requires the current approved lineage and source revision; it does not
consume a release or append a review event. Generic release/consume operations
refuse this source kind; the approval grants no sink permit. A reviewer approval identifies the
source assertions accepted for this bounded analysis; it does not authenticate
the original author or establish truth for an entire corpus.

The taxonomy report applies the existing bounded Kotlin positive-fragment
explanation over the complete approved selection. Evidence display is paged;
each report labels its proof scope separately from the displayed page. Its
source quotations, revision, approval and content identities remain visible.
SUPPORTED is positive derivability in that selected fragment, and UNKNOWN is
not a negative conclusion. This path does not invoke SUMO-Nix or mutate a global
fact, evidence, or attention store. Existing reviewed book modalities remain
excluded from asserted taxonomy.
